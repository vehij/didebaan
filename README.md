# دیده‌بان

اپ دسکتاپ مک برای مدیریت اکانت‌های کلاد و دستگاه‌هایی که رویشان لاگین هستند.

## دانلود و نصب

1. به صفحه‌ی [**Releases**](https://github.com/vehij/didebaan/releases/latest) برو و فایل `.dmg` را از بخش **Assets** دانلود کن. این فایل روی هر دو نوع مک (Apple Silicon و Intel) کار می‌کند.
2. بازش کن و آیکون **Didebaan** را روی پوشه‌ی **Applications** بکش.
3. اپ را از پوشه‌ی Applications باز کن.
4. وقتی پرسید اجازه‌ی نوتیفیکیشن می‌دهی، **Allow** را بزن.

اگر اپ بار اول باز نشد، بخش بعدی را ببین. این فقط یک بار لازم است.

## اگر اپ باز نشد

دیده‌بان با حساب پولی Apple Developer امضا نشده، برای همین مک بار اول به آن اعتماد نمی‌کند. بسته به پیامی که می‌بینی:

### پیام «Apple could not verify "Didebaan" is free of malware…»

1. روی **Done** بزن (نه Move to Trash).
2. منوی Apple (آیکون سیب گوشه‌ی بالای صفحه) › **System Settings** › **Privacy & Security** را باز کن.
3. پایین صفحه، در بخش Security، کنار پیام مربوط به Didebaan روی **Open Anyway** بزن و رمز مک را وارد کن.
4. دوباره دیده‌بان را باز کن و **Open** را بزن.

### پیام «"Didebaan" is damaged and can't be opened»

این پیام یعنی مک فایل دانلودشده را قرنطینه کرده؛ اپ خراب نیست. با یک دستور درست می‌شود:

1. اول دیده‌بان را به پوشه‌ی **Applications** کشیده باشی.
2. **Terminal** را باز کن: کلید <kbd>⌘</kbd> + <kbd>Space</kbd> را بزن، بنویس `Terminal` و <kbd>Enter</kbd> را بزن.
3. این خط را کپی کن، در Terminal بچسبان و <kbd>Enter</kbd> را بزن:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Didebaan.app
   ```

   اگر چیزی چاپ نشد، یعنی درست انجام شد. این دستور فقط برچسب «دانلودشده از اینترنت» را از روی همین اپ برمی‌دارد و به چیز دیگری دست نمی‌زند.
4. Terminal را ببند و دیده‌بان را دوباره باز کن.

این کار فقط برای نصب اول لازم است؛ به‌روزرسانی‌هایی که خود اپ نصب می‌کند دوباره این پیام را نمی‌آورند.

## به‌روزرسانی

از نسخه‌ی **0.3.0** به بعد، دیده‌بان خودش نسخه‌ی جدید را بررسی می‌کند؛ از **0.7.0** هر ساعت، حتی وقتی پنجره بسته است و فقط آیکون منوبار باز است. وقتی نسخه‌ی تازه‌ای منتشر شود، یک نوتیفیکیشن می‌آید و بالای داشبورد نوار «نسخه‌ی جدید آماده است» با فهرست تغییرات نشان داده می‌شود. با زدن **به‌روزرسانی و باز کردن دوباره**، نسخه‌ی جدید دانلود و نصب می‌شود و اپ خودش دوباره باز می‌شود. داده‌ها سر جایشان می‌مانند. از **تنظیمات › به‌روزرسانی** هم می‌شود دستی بررسی کرد.

اگر نسخه‌ی 0.2.0 را نصب کرده‌ای، یک بار نسخه‌ی جدید را مثل نصب اول دستی نصب کن؛ از آن به بعد به‌روزرسانی خودکار است.

## همگام‌سازی خودکار مصرف

افزونه‌ی **دیده‌بان همراه** روی Chrome هر لپ‌تاپی که اکانت کلاد رویش است (مک یا ویندوز)، هر دو ساعت همان عددهای صفحه‌ی **Settings › Usage** در claude.ai را می‌خواند: لیمیت **This week**، لیمیت **Fable**، زمان ریست هر کدام و سهم Claude Code، Chats و Cowork از مصرف هفته. هر وقت صفحه‌ی **Settings › Billing** را باز کنی، **تاریخ تمدید** اشتراک را هم برمی‌دارد (فقط همان تاریخ؛ نه کارت، نه مبلغ، نه فاکتورها). این مصرف کل اکانت است، از هر جایی که استفاده شده باشد. عددها به سرور خودت روی Cloudflare می‌روند و دیده‌بان روی مکت هر چند دقیقه آن‌ها را می‌گیرد و کارت اکانتی را که **همان ایمیل** را دارد به‌روز می‌کند.

### ۱. روی مک، در دیده‌بان

**تنظیمات › همگام‌سازی خودکار مصرف › فعال‌سازی همگام‌سازی** را بزن و «کد اتصال» را کپی کن. این کد مثل رمز است؛ فقط روی دستگاه‌های خودت از آن استفاده کن.

### ۲. روی هر لپ‌تاپ، یک بار

1. از صفحه‌ی [Releases](https://github.com/vehij/didebaan/releases/latest) فایل `didebaan-companion.zip` را دانلود کن و بازش کن (دو بار کلیک). پوشه‌ی بازشده را جایی بگذار که پاکش نکنی، مثلاً در Documents؛ Chrome افزونه را از همین پوشه اجرا می‌کند.
2. در Chrome به آدرس `chrome://extensions` برو.
3. کلید **Developer mode** را بالا سمت راست روشن کن.
4. **Load unpacked** را بزن و پوشه‌ی بازشده را انتخاب کن.
5. روی آیکون پازل 🧩 کنار نوار آدرس بزن و کنار **Didebaan Companion** روی سنجاق بزن تا آیکونش همیشه دیده شود.
6. روی آیکون افزونه بزن، کد اتصال را بچسبان، **اتصال** را بزن و یک نام برای دستگاه بنویس (مثلاً MacBook Air).
7. مطمئن شو در همین Chrome به claude.ai با همان اکانت وارد شده‌ای. اگر روی آن لپ‌تاپ فقط با اپ دسکتاپ کلاد کار می‌کنی، یک بار در Chrome هم وارد شو.

از این به بعد هر دو ساعت خودش می‌فرستد. برای تاریخ تمدید، ماهی یک بار صفحه‌ی Billing را باز کن (در پنجره‌ی افزونه دکمه‌اش هست)؛ اگر تاریخ تمدید را بعداً در دیده‌بان دستی عوض کنی، همان تاریخ دستی می‌ماند تا Billing دوباره باز شود. با باز کردن صفحه‌ی Usage در claude.ai یا زدن «همگام‌سازی الان» در افزونه، همان لحظه هم می‌فرستد. اگر ایمیلی برسد که در دیده‌بان اکانتی با آن نیست، در تنظیمات نشانش می‌دهد تا با یک کلیک اضافه‌اش کنی.

### چیزهایی که خوب است بدانی

- کلاد برای این عددها API رسمی ندارد؛ افزونه همان چیزی را می‌خواند که صفحه‌ی Usage نشان می‌دهد. اگر کلاد آن را عوض کند، افزونه ممکن است تا نسخه‌ی بعدی کار نکند؛ در این حالت روی کارت اکانت نوشته می‌شود عدد آخر چند ساعت پیش آمده. در پنجره‌ی افزونه بخش **عیب‌یابی** متنی می‌دهد (بدون اسم و ایمیل) که برای درست کردنش کافی است.
- افزونه فقط وقتی کار می‌کند که Chrome باز و لپ‌تاپ روشن باشد.
- برای نسخه‌ی جدید افزونه، zip تازه را دانلود کن، محتوای پوشه‌ی قبلی را با آن عوض کن و در `chrome://extensions` روی دکمه‌ی بارگذاری دوباره‌ی افزونه بزن.

### راه‌اندازی یک‌باره‌ی سرور (برای نگهدارنده‌ی پروژه)

سرور یک Cloudflare Worker رایگان است (پوشه‌ی `sync/`) که GitHub Actions منتشرش می‌کند. یک بار:

1. در [dash.cloudflare.com](https://dash.cloudflare.com) از منوی پروفایل به **My Profile › API Tokens › Create Token** برو، قالب **Edit Cloudflare Workers** را انتخاب کن، در Account Resources حساب `Yaghobian@gmail.com's Account` را بگذار و توکن را بساز و کپی کن.
2. در ریپو به **Settings › Secrets and variables › Actions › New repository secret** برو و توکن را با نام `CLOUDFLARE_API_TOKEN` ذخیره کن.
3. در تب **Actions**، workflow **Deploy sync server** را با **Run workflow** اجرا کن.

## امکانات

- ثبت **دستگاه‌ها** و **اکانت‌ها** (یک اکانت می‌تواند روی چند دستگاه باشد)
- وضعیت **فعال / غیرفعال** هر اکانت
- دو لیمیت هفتگی جدا: **لیمیت کل** و **لیمیت Fable**، هر کدام با روز و ساعت ریست خودش
- **ریست خودکار**: وقتی زمان ریست هفتگی برسد، درصد مصرف خودش صفر می‌شود و در تاریخچه ثبت می‌شود
- **پروژه برای اکانت‌ها و دستگاه‌ها** (مثلاً «پروژه میرزا») روی کارت‌ها، در جستجو و در منوبار، با **فیلتر پروژه** در داشبورد و صفحه‌ی دستگاه‌ها
- **تاریخ تمدید** با تقویم انتخابی **شمسی یا میلادی** (هر روز تاریخ تقویم دیگر را هم کوچک نشان می‌دهد) و شمارش روزهای باقی‌مانده
- **انتخاب ساعت روی نوار آسمان**: از شب تا طلوع، روز و غروب؛ بکش، یا با دکمه‌های بالا/پایین و میان‌برهای صبح، ظهر، عصر و شب دقیقش کن
- پیشنهاد «الان با کدام اکانت کار کنم؟» برای کار عمومی و برای Fable
- نقشه‌ی دستگاه × اکانت، تاریخچه‌ی مصرف، پشتیبان‌گیری و بازگردانی
- **آیکون منوبار** با پنجره‌ی خلاصه: پیشنهاد اکانت، درصد همه‌ی اکانت‌ها و هشدارها، بدون باز کردن داشبورد
- **نوتیفیکیشن** برای رسیدن به سقف، ریست هفتگی و نزدیک شدن به تمدید (هر کدام فقط یک بار)
- اجرای خودکار و بی‌صدا با روشن شدن مک (از تنظیمات)؛ بستن پنجره اپ را نمی‌بندد و در منوبار می‌ماند
- **به‌روزرسانی از داخل اپ** با یک دکمه
- **همگام‌سازی خودکار مصرف** از claude.ai روی لپ‌تاپ‌های دیگر (مک و ویندوز) با افزونه‌ی Chrome، شامل سهم Claude Code، Chats و Cowork
- حالت تاریک خودکار همراه با تنظیمات مک

همه‌ی داده‌ها روی همین مک ذخیره می‌شوند (فایل `didebaan.json` در پوشه‌ی داده‌ی اپ، با یک نسخه‌ی قبلی `didebaan.json.bak`). هیچ رمز یا کوکی claude.ai در اپ یا افزونه نگه داشته نمی‌شود. تنها چیزی که از دستگاه بیرون می‌رود، اگر همگام‌سازی خودکار را روشن کنی، عددهای مصرف، ایمیل اکانت و نام دستگاه است که به سرور Cloudflare خودت فرستاده می‌شود.

## ساختار

| مسیر | توضیح |
|---|---|
| `src/` | رابط کاربری با React و TypeScript |
| `src/lib/time.ts` | منطق ریست هفتگی، شمارش معکوس و پیشنهاد اکانت |
| `src/lib/jalali.ts` | تبدیل تاریخ شمسی و میلادی |
| `src/lib/store.ts` | وضعیت برنامه و ذخیره‌ی خودکار |
| `src/lib/notify.ts` | نوتیفیکیشن‌های سقف، ریست و تمدید |
| `src/lib/updater.ts` | بررسی و نصب نسخه‌ی جدید |
| `src/lib/sync.ts`، `src/lib/remote.ts` | گرفتن گزارش‌های افزونه از سرور و اعمالشان روی اکانت‌ها |
| `extension/` | افزونه‌ی Chrome «دیده‌بان همراه» (بدون مرحله‌ی build؛ همین پوشه نصب می‌شود) |
| `sync/` | سرور همگام‌سازی روی Cloudflare Workers |
| `src-tauri/` | پوسته‌ی دسکتاپ Tauri 2 (Rust) و ذخیره‌ی فایل روی دیسک |

فونت‌ها داخل خود اپ هستند و به اینترنت نیازی ندارند: **Estedad** برای فارسی و **JetBrains Mono** برای اعداد و متن انگلیسی.

## انتشار نسخه‌ی جدید (برای نگهدارنده‌ی پروژه)

همه از روی سایت گیت‌هاب، بدون ترمینال:

1. در ریپو به تب **Actions** برو و از فهرست سمت چپ **Release macOS app** را انتخاب کن.
2. روی **Run workflow** بزن، شماره‌ی نسخه‌ی جدید (مثلاً `0.4.0`) و یک خط درباره‌ی تغییرات بنویس و دوباره **Run workflow** را بزن.
3. حدود پنج دقیقه بعد نسخه در Releases منتشر می‌شود و اپ‌های نصب‌شده خبردار می‌شوند.

شماره‌ی نسخه باید از نسخه‌ی قبلی بزرگ‌تر باشد، وگرنه اپ‌ها آن را به‌روزرسانی حساب نمی‌کنند.

### تنظیم یک‌باره

به‌روزرسانی خودکار به این دو چیز نیاز دارد:

- **ریپو باید Public باشد.** اپ‌ها بدون ورود به گیت‌هاب فایل‌های به‌روزرسانی را از Releases می‌خوانند و از ریپوی Private نمی‌توانند. (Settings › General › Danger Zone › Change visibility.) در کد هیچ رمز یا اطلاعات شخصی‌ای نیست.
- **کلید امضای به‌روزرسانی** باید در Settings › Secrets and variables › Actions › **New repository secret** با نام `TAURI_SIGNING_PRIVATE_KEY` ذخیره شده باشد. اپ فقط فایل‌هایی را نصب می‌کند که با این کلید امضا شده باشند، پس از این کلید یک نسخه‌ی پشتیبان جای امنی نگه دار. اگر گم شود، کاربران باید یک بار نسخه‌ی جدید را دستی نصب کنند.

## اجرا از روی کد (برای توسعه)

پیش‌نیازها (یک بار):

```bash
xcode-select --install                                           # ابزارهای خط فرمان Xcode
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust
brew install node                                                # Node.js نسخه‌ی 20 یا بالاتر
```

اجرای نسخه‌ی توسعه:

```bash
npm install
npm run tauri dev
```

ساخت فایل نصبی (`.app` و `.dmg`):

```bash
npm run tauri build
```

خروجی در `src-tauri/target/release/bundle/` ساخته می‌شود.

## توسعه

```bash
npm run dev        # فقط رابط کاربری در مرورگر؛ داده‌ها در localStorage مرورگر ذخیره می‌شوند
                   # پنجره‌ی منوبار: http://localhost:1420/#tray
npm test           # تست‌های منطق ریست و تاریخ
npm run typecheck
```
