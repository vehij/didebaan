# دیده‌بان

اپ دسکتاپ مک برای مدیریت اکانت‌های کلاد و دستگاه‌هایی که رویشان لاگین هستند.

## دانلود و نصب (بدون ترمینال)

1. به صفحه‌ی [**Releases**](https://github.com/vehij/didebaan/releases/latest) برو و فایل `.dmg` را از بخش **Assets** دانلود کن. این فایل روی هر دو نوع مک (Apple Silicon و Intel) کار می‌کند.
2. بازش کن و آیکون **Didebaan** را روی پوشه‌ی **Applications** بکش.
3. اپ را باز کن. بار اول مک می‌گوید نمی‌تواند سازنده را تأیید کند (چون اپ با حساب پولی Apple Developer امضا نشده). **Done** را بزن، بعد به **System Settings › Privacy & Security** برو و پایین صفحه، کنار پیام Didebaan، روی **Open Anyway** بزن. این فقط یک بار لازم است.
4. وقتی پرسید اجازه‌ی نوتیفیکیشن می‌دهی، **Allow** را بزن.

برای نسخه‌ی جدید همین کار را با فایل تازه تکرار کن؛ داده‌ها سر جایشان می‌مانند.

## امکانات

- ثبت **دستگاه‌ها** و **اکانت‌ها** (یک اکانت می‌تواند روی چند دستگاه باشد)
- وضعیت **فعال / غیرفعال** هر اکانت
- دو لیمیت هفتگی جدا: **لیمیت کل** و **لیمیت Fable**، هر کدام با روز و ساعت ریست خودش
- **ریست خودکار**: وقتی زمان ریست هفتگی برسد، درصد مصرف خودش صفر می‌شود و در تاریخچه ثبت می‌شود
- **تاریخ تمدید** شمسی، با شمارش روزهای باقی‌مانده
- پیشنهاد «الان با کدام اکانت کار کنم؟» برای کار عمومی و برای Fable
- نقشه‌ی دستگاه × اکانت، تاریخچه‌ی مصرف، پشتیبان‌گیری و بازگردانی
- **آیکون منوبار** با پنجره‌ی خلاصه: پیشنهاد اکانت، درصد همه‌ی اکانت‌ها و هشدارها، بدون باز کردن داشبورد
- **نوتیفیکیشن** برای رسیدن به سقف، ریست هفتگی و نزدیک شدن به تمدید (هر کدام فقط یک بار)
- اجرای خودکار و بی‌صدا با روشن شدن مک (از تنظیمات)؛ بستن پنجره اپ را نمی‌بندد و در منوبار می‌ماند
- حالت تاریک خودکار همراه با تنظیمات مک

همه‌ی داده‌ها فقط روی همین مک ذخیره می‌شوند (فایل `didebaan.json` در پوشه‌ی داده‌ی اپ، با یک نسخه‌ی قبلی `didebaan.json.bak`). هیچ رمز یا توکنی در اپ نگه داشته نمی‌شود.

## ساختار

| مسیر | توضیح |
|---|---|
| `src/` | رابط کاربری با React و TypeScript |
| `src/lib/time.ts` | منطق ریست هفتگی، شمارش معکوس و پیشنهاد اکانت |
| `src/lib/jalali.ts` | تبدیل تاریخ شمسی و میلادی |
| `src/lib/store.ts` | وضعیت برنامه و ذخیره‌ی خودکار |
| `src-tauri/` | پوسته‌ی دسکتاپ Tauri 2 (Rust) و ذخیره‌ی فایل روی دیسک |

فونت‌ها داخل خود اپ هستند و به اینترنت نیازی ندارند: **Estedad** برای فارسی و **JetBrains Mono** برای اعداد و متن انگلیسی.

## ساخت نسخه‌ی جدید

نسخه را در `package.json`، `src-tauri/tauri.conf.json` و `src-tauri/Cargo.toml` بالا ببر و یک تگ مثل `v0.3.0` بزن (یا از تب **Actions** گیت‌هاب، workflow با نام *Release macOS app* را دستی اجرا کن). GitHub Actions روی مک فایل `.dmg` را می‌سازد و در Releases می‌گذارد.

## اجرا از روی کد (برای توسعه)

پیش‌نیازها (یک بار):

```bash
xcode-select --install                                           # ابزارهای خط فرمان Xcode
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust
brew install node                                                # Node.js نسخه‌ی 20 یا بالاتر
```

اجرای نسخه‌ی توسعه:

```bash
npm install
npm run tauri dev
```

ساخت فایل نصبی (`.app` و `.dmg`):

```bash
npm run tauri build
```

خروجی در `src-tauri/target/release/bundle/` ساخته می‌شود.

## توسعه

```bash
npm run dev        # فقط رابط کاربری در مرورگر؛ داده‌ها در localStorage مرورگر ذخیره می‌شوند
                   # پنجره‌ی منوبار: http://localhost:1420/#tray
npm test           # تست‌های منطق ریست و تاریخ
npm run typecheck
```
